ElectroMart SQL Retail Sales Analysis

Project Overview

This project focuses on analyzing ElectroMart retail data using MySQL. The dataset contains customer, product, and sales information. I used SQL queries to extract business insights related to revenue, orders, customers, products, payment modes, brands, and customer spending.
